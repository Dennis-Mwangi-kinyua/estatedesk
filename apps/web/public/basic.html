Older phones and app availability

This overview is designed for simple browsers and slow connections. Links open the full site, which needs a modern browser for dashboard operations. The full web app targets Chrome, Edge and Firefox 111+, or Safari 16.4+.

An installable web app is available in supported browsers. Native Android/iOS apps and desktop packaging exist in source; signing, device acceptance and store releases remain pending.
